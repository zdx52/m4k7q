# libretv-sources

把 [ziyuanzhan](https://mylazily.github.io/ziyuanzhan/) 的在线影视采集站列表，转成 LibreTV 能订阅的格式。每 6 小时自动更新。

订阅地址：

```
https://zdx52.github.io/libretv-sources/libretv-sources.json
```

LibreTV → 设置 → 数据源订阅 → 粘贴上面地址 → 订阅。

> 别用 `raw.githubusercontent.com` 的地址：容器那边访问它会超时，只有 `*.github.io` 通。

数据是第三方采集站，可用性不保证；进 LibreTV 后点「批量测活」看实际能用几个。
